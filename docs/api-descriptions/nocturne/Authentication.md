Sign-in for people, and tokens for apps. To choose a method for your client, read the **Authentication** guide first.

```resources Authentication
```

## Good to know

- All OAuth clients are public. There are no client secrets, and PKCE with `S256` is required.
- An API token is shown once, when it is created. Keep it as safe as a password.
- Only a person who is signed in can create an API token.
