Glucose values, kept as four record types because each comes from a different source with a different accuracy.

```resources Glucose
```

## Good to know

- Each resource in this group has the same operations: list, read, create, create in bulk, update, delete, list deleted and restore. The **Conventions** section of the introduction describes paging, time ranges and deleted records.
- To draw a chart, use [Chart Data](#nocturne/tag/chart-data). It returns the readings and everything drawn with them in one call.
- A legacy Nightscout entry is stored as one of these record types. The Nightscout API reference shows the mapping.
