The Nightscout v1 API. Responses match the original JavaScript implementation, so an uploader or follower app that works with Nightscout works here with no change.

```resources Nightscout V1
```

## Good to know

- An entry must carry `date` in Unix milliseconds.
- Send the API secret, as its SHA-1 hash, in the `api-secret` header. A token in the `token` query parameter also works.
- Nocturne has no separate tables for legacy data. A write is stored as v4 records and a read is built from them. See the **Data Model** pages.
