The Nightscout v3 API: the same operations on each collection, with support for conditional requests.

```resources Nightscout V3
```

## Good to know

- The key of a document is `identifier`, a string. It is not the MongoDB `_id` that v1 uses.
- A read accepts `If-Modified-Since` and returns `Last-Modified`.
- Nocturne has no separate tables for legacy data. A write is stored as v4 records and a read is built from them. See the **Data Model** pages.
